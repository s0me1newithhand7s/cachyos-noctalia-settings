# cachyos-umbriel-noctalia

This projects contains CachyOS'es settings for Noctalia projects: [**Noctalia Shell**](https://github.com/noctalia-dev/noctalia) and [**Noctalia Greeter**](https://github.com/noctalia-dev/noctalia-greeter).

## Project tree:

there is 3 main directories:

### `etc/skel/.config/nocalia/`

Contains `bar.toml`, `misc.toml`, `shell.toml`, `theme.toml` and `widget.toml` files under `config/` directory, `config.toml` with includes of listed files.

### `usr/share/noctalia-greeter/`

Contains `config.toml` with session configuration.

### `var/lib/noctalia-greeter`

Contains `greeter.toml` with greeter configuration.
